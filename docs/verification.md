# Проверка первой версии

Проверенный коммит приложения: `d7f0ace299f849ad217898c23bf8d0e807bc3d37`.
GitHub Actions: https://github.com/stepankovner/mabetek/actions/runs/41346849985

- Первые требования и 20 серверных сценариев, а также браузерные сценарии зафиксированы в `3c167cd` до прикладного кода. Проверка извлечённого первого коммита завершается отсутствием `app`, как и ожидается до реализации.
- После реализации добавлены проверки реальной SMTP-доставки, CRUD админки, ротации сессий, параллельных повторов и ограничений безопасности: всего 33 серверных теста.
- Серверные тесты проходят на временной SQLite и настоящем PostgreSQL 18; локальное покрытие исполняемых строк приложения — 91%. Это не эквивалент полного покрытия всех возможных сценариев.
- Production-сборка Next.js и проверка TypeScript проходят.
- 18 браузерных сценариев проходят в GitHub Actions: desktop и mobile, страницы, навигация, ошибка/повтор/успех формы, выключенный приём и 404.
- В CI собраны и запущены PostgreSQL, миграции, API, worker, Next.js и Caddy. Проверены маршрутизация, readiness, каталог, страница входа, резервная копия и её восстановление в отдельную БД.
- Локально через браузер проверены внешний вид, мобильное меню, отсутствие горизонтального переполнения главной на ширине 390 px и реальная отправка синтетической заявки; запись и задача уведомления подтверждены SQL-запросом.

## Границы проверки

Браузерные тесты формы подменяют ответы API, а реальные сохранение, очередь и SMTP покрываются серверными тестами и локальной сквозной проверкой. Письмо отправлялось только на одноразовый локальный SMTP-сервер. Реальный почтовый провайдер, внешний DNS, публичный TLS и рабочий сервер ещё не настроены.

Контейнерная проверка выполнена успешно в GitHub Actions: локальное скачивание базовых Docker-образов зависало на сети и было остановлено. Это не влияет на зелёную проверку контейнеров в CI.

Страницы, юридические сведения и фото требуют заполнения/проверки перед публикацией. Файлы изображений из референса временные, см. `assets.md`. Приём заявок и индексация по умолчанию выключены. Публикация в production в рамках этой разработки не выполнялась.
