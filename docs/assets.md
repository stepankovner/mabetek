# Изображения и шрифты

## Временные изображения из утверждённого макета

`frontend/public/images/hero.jpg`: иллюстрация склада, подготовленная для ранее выбранного пользователем макета. Это не территория Мабетэк.

`reference.jpg`: предоставленный пользователем скриншот Priority1 Logistics. Используется как временный источник двух фоновых фрагментов для сохранения утверждённого внешнего вида. Это **не готовый лицензированный набор коммерческих фотографий**. Перед публичным запуском заменить оба фрагмента своими/лицензированными изображениями и убрать этот файл.

`logo.jpg`: лист вариантов словесного логотипа, из которого CSS показывает выбранный вариант №4. Временный технический носитель: перед финальным запуском заменить самостоятельным подготовленным файлом выбранного знака.

## Шрифты

Manrope и Golos Text взяты из официального репозитория Google Fonts:
- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/golostext

Файлы переменных шрифтов хранятся локально, лицензии OFL — рядом в `frontend/public/fonts/`. Посетитель не обращается к Google Fonts.
